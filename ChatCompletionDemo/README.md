# ChatCompletionDemo

Minimal Python 3.12 demo using the OpenAI SDK and Chat Completions.

## Requirements

- Python 3.12
- An OpenAI API key in `OPENAI_API_KEY`

## Quick start

1. Create and activate a virtual environment with Python 3.12.
2. Install dependencies:
   - `pip install -r requirements.txt`
3. Set API key:
   - PowerShell: `$env:OPENAI_API_KEY="your_key_here"`
4. Run:
   - `python main.py`
